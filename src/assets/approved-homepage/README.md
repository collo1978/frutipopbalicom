# Approved homepage artwork

The original supplied SVG is retained by `original-desktop.svg.asset.json`. The image layers are extracted byte-for-byte without repainting, resizing, or changing packaging. `desktop.svg` preserves the original composition, removes its duplicate header area, externalizes image data, and uses a correctly sized local order-link hit region. React updates the supplied speech text every six seconds when visible and motion is allowed.

Mobile arranges the six original package layers independently. The headline, original mascot, and three-child photo are displayed through cropped SVG windows onto the supplied scene, not generated replacements. Existing original project imagery remains intact.
